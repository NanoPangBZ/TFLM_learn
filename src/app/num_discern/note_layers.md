## 0. 速查表

| 概念 | 类别 | 一句话解释 | 有可训练参数吗 |
|---|---|---|---|
| **输入层** | 角色/位置 | 存放原始数据，定义模型接口 | ❌ 没有 |
| **隐藏层** | 角色/位置 | 把数据变换成更有用的中间表示 | ✅ 有 |
| **输出层** | 角色/位置 | 把表示映射成任务答案 | ✅ 有 |
| **MLP** | 网络架构 | 相邻层全部连接的前馈网络 | —（架构本身） |
| **CNN** | 网络架构 | 局部连接 + 权重共享的前馈网络 | —（架构本身） |

一句话：

> 输入层是入口，隐藏层是加工厂，输出层是出口；MLP 让所有车间两两全连接，CNN 让每个车间只盯局部并共用工具，最后通常再接一个 MLP 车间做决策。

## 1. 总图景：网络是层的复合

神经网络本质上是一个**由很多层叠起来的函数**：

```
输入张量 x
   │  第 1 层
   ▼
中间张量 h1
   │  第 2 层
   ▼
中间张量 h2
   │  ...
   ▼
输出张量 y
```

数学上：

```
y = f_L( ... f_2( f_1(x) ) ... )
```

每一层都做同一件事：**接收一个张量，输出另一个张量**。

层的“角色”由位置决定：

| 角色 | 位置 | 参数 | 作用 |
|---|---|---|---|
| **输入层** | 第 0 层 | 无 | 存放数据，定义接口 |
| **隐藏层** | 中间任意层 | 有 | 特征变换 |
| **输出层** | 最后一层 | 有 | 任务答案 |

而 **MLP / CNN 是“怎么组织隐藏层”的两种架构**，不是另外三种层。

---

## 2. 神经元：所有层的基本单元

### 2.1 计算

一个神经元做三步：

```
z = w1*x1 + w2*x2 + ... + wn*xn + b     // 加权求和 + 偏置
a = f(z)                                 // 激活函数
```

- `x1..xn`：来自上一层的输入；
- `w1..wn`：权重，表示“这个输入有多重要”；
- `b`：偏置，表示“这个神经元有多容易被激活”；
- `f`：激活函数，常见的是 ReLU：`f(z) = max(0, z)`。

### 2.2 直觉

一个神经元就是一个**模式检测器**。

比如隐藏层某个神经元想检测“画面中间有没有一竖”：

- 对中间那一列像素给正权重；
- 对两边像素给负权重；
- 当中间有笔迹、两边空白时，加权和很大，ReLU 后输出高值；
- 否则输出 0。

权重不是人手工设的，是训练出来的。

### 2.3 为什么必须有激活函数

如果没有 `f`，两层线性变换叠起来：

```
h  = W1*x + b1
y  = W2*h + b2
   = (W2*W1)*x + (W2*b1 + b2)
```

仍然等价于**一层**线性变换。网络再深也没有意义。

加上 ReLU 后，函数变成分段线性，可以逼近曲线、可以划出复杂的决策边界。

### 2.4 代码形态

```c
float z = b;
for (int j = 0; j < n; j++)
    z += w[j] * x[j];
float a = (z > 0.0f) ? z : 0.0f;   // ReLU
```

`num_discern` 的隐藏层就是 32 个这样的神经元并行计算。

## 3. 输入层

### 3.1 它是什么

输入层**不是计算层**，它只是“数据的容器”：

- 没有权重；
- 没有偏置；
- 没有激活函数；
- 不参与训练。

在 Keras 里：

```python
tf.keras.layers.Input(shape=(784,))
```

这行只是声明“输入是一个长度 784 的向量”，并没有创建可训练参数。

在 C 里，输入层甚至不是结构体，只是一个指针：

```c
int num_discern_predict(const float* input);
```

### 3.2 为什么是 784

MNIST 图片是 28×28：

```
28 × 28 = 784
```

图片被**按行展开**成一维向量：

```
index = y * 28 + x
```

第 0 行 28 个像素放进 `input[0..27]`，第 1 行放进 `input[28..55]`，……最后一行放进 `input[756..783]`。

### 3.3 输入层的“契约”

输入层虽然不计算，但它规定了模型对数据的要求：

| 契约 | `num_discern` 的做法 | 违反后果 |
|---|---|---|
| 尺寸 | 28×28 | 维度不匹配或信息丢失 |
| 展平顺序 | 行优先 `y*28+x` | 形状仍匹配，但权重全错位，准确率接近随机 |
| 极性 | 白字黑底 | 准确率崩 |
| 归一化 | `/255`，值域 `[0,1]` | 分布偏移，准确率下降 |
| 通道 | 单通道灰度 | 维度/语义错 |
| 类型 | `float32` | C 侧读错内存 |

实际工程里，**预处理（反相、裁剪、居中、归一化）可以看作“输入层的一部分”**。

### 3.4 输入层有没有“神经元”

有“节点”，但那些节点只是数据值，不是计算单元。说“输入层有 784 个神经元”是一种方便的说法，严格说它们不激活、不学习。

## 4. 隐藏层

### 4.1 它是什么

**输入层和输出层之间的所有层，都叫隐藏层。**

隐藏层是真正干活的地方：

```
z = W * x + b
h = ReLU(z)
```

- `W`：权重矩阵；
- `b`：偏置向量；
- `ReLU`：激活函数；
- `h`：这一层提取出的“新表示”。

`num_discern` 的隐藏层是 32 个神经元：

```c
for (int i = 0; i < 32; i++) {
    float s = nd_b1[i];
    for (int j = 0; j < 784; j++)
        s += input[j] * nd_w1[j * 32 + i];
    hidden[i] = (s > 0.0f) ? s : 0.0f;   // ReLU
}
```

每个隐藏神经元都连到全部 784 个输入，所以第一层有：

```
784 × 32 = 25 088 个权重
+ 32 个偏置
```

### 4.2 隐藏层在“学什么”

它把 784 维的像素空间，压缩成 32 维的特征空间：

- 输入：`x[784]`，每个维度是一个像素；
- 输出：`h[32]`，每个维度是某种“组合特征”的强度。

在只有一层隐藏层的 MLP 里，这 32 个神经元更像是 **32 个全局模板**：

- 有的对“中间一竖”敏感；
- 有的对“上方一个圈”敏感；
- 有的对“右下角的钩”敏感；
- ……

它们不是 CNN 那种“边缘 → 笔画 → 部件”的层级特征，因为 MLP 没有局部连接和权重共享，每个神经元都看整张图。

### 4.3 宽度和深度

| 概念 | 含义 | 本仓库 |
|---|---|---|
| **宽度** | 一层有多少个神经元 | 32 |
| **深度** | 有多少个隐藏层 | 1 |

- 宽度越大，能表达的模式越多，但参数和计算量增加；
- 深度越大，能组合出更抽象的特征，但训练更难、更容易过拟合。

“深度学习”的“深”，指的就是隐藏层多。

### 4.4 为什么需要隐藏层

经典例子是 XOR：

- 一条直线无法把 `(0,0)`、`(1,1)` 和 `(0,1)`、`(1,0)` 分开；
- 加一个隐藏层后，可以先把它映射到新的空间，再用一条直线分开。

隐藏层的作用就是：**把原始空间中“线性不可分”的问题，变换成新空间中“线性可分”的问题。**

### 4.5 偏置和激活

- **偏置 b**：让神经元有一个“基础激活水平”，相当于把激活阈值左右移动；
- **ReLU**：把负值压成 0，保留正值；计算简单，适合单片机；
- 其他激活：Sigmoid、Tanh、LeakyReLU、GELU……隐藏层最常用 ReLU。

### 4.6 隐藏层是计算大头

`num_discern` 的第一层占了全部乘加的 **98.7%**：

```
第一层：784 × 32 = 25 088
第二层：32 × 10  =    320
```

所以优化推理速度，首先看第一层；量化省内存，也主要省第一层的权重。

## 5. 输出层

### 5.1 它是什么

输出层是最后一层，把隐藏层的表示映射成**任务需要的答案**。

`num_discern` 是 10 分类，所以输出 10 个数：

```c
for (int k = 0; k < 10; k++) {
    float s = nd_b2[k];
    for (int i = 0; i < 32; i++)
        s += hidden[i] * nd_w2[i * 10 + k];
    out[k] = s;
}
```

这 10 个数叫 **logits**（得分），分别对应数字 0–9。

### 5.2 输出层怎么变成“答案”

训练时，Keras 的最后一层是：

```python
Dense(10, activation="softmax")
```

softmax 把 10 个得分变成概率：

```
p[k] = exp(out[k]) / Σ_j exp(out[j])
```

- 所有 `p[k]` 在 `[0,1]`；
- 总和为 1；
- 哪个概率大，就认为输入是哪个数字。

训练用的损失是交叉熵：

```
loss = -log(p[真实标签])
```

正确类别的概率越高，损失越小。

### 5.3 推理时为什么可以不要 softmax

softmax 是**单调递增**的：得分最大的类别，概率也最大。

所以分类只需要 **argmax**：

```c
int best = 0;
for (int k = 1; k < 10; k++)
    if (out[k] > out[best]) best = k;
return best;
```

C 代码里没有 softmax，不是漏了，而是不需要：

- 训练时 softmax + 交叉熵，梯度形式简单；
- 推理时只取最大下标，省掉 10 次指数运算。

### 5.4 输出层的参数

```
32 × 10 = 320 个权重
+ 10 个偏置
```

比第一层小得多。

### 5.5 输出层一定要 softmax 吗

不一定，取决于任务：

| 任务 | 输出层 | 损失 |
|---|---|---|
| 多分类（互斥） | 10 个 logits + softmax | 交叉熵 |
| 二分类 | 1 个 logit + sigmoid | 二元交叉熵 |
| 多标签（不互斥） | 每类一个 sigmoid | 二元交叉熵 |
| 回归 | 1 个线性输出 | MSE |

关键是：**输出层的形状和激活，由任务决定。**

## 6. MLP 是什么

### 6.1 定义

**MLP = Multi-Layer Perceptron，多层感知机。**

它满足三个条件：

1. 至少有一个隐藏层；
2. 相邻层之间**全连接**（每个神经元连到上一层的所有神经元）；
3. 信号只向前传（前馈），没有环。

`num_discern` 的 `784 → 32 → 10` 就是一个标准的 1 隐藏层 MLP。

### 6.2 结构图

```
输入层 784          隐藏层 32           输出层 10
x[0]  ────────┐
x[1]  ────────┼──► h[0] ────────┐
 ...  ────────┤    h[1] ────────┼──► y[0]
x[783]────────┘    ...          ├──► y[1]
                    h[31]───────┘    ...
                                     y[9]
```

- 每个 `h[i]` 都连到所有 `x[j]`；
- 每个 `y[k]` 都连到所有 `h[i]`。

这就是“全连接（fully connected）”或“稠密（dense）”的含义。

### 6.3 数学表达

```
h = ReLU(W1 * x + b1)
y = W2 * h + b2
```

- `W1` 形状 `(784, 32)`；
- `b1` 形状 `(32,)`；
- `W2` 形状 `(32, 10)`；
- `b2` 形状 `(10,)`。

### 6.4 参数量公式

对每个全连接层：

```
参数 = (输入维度 + 1) × 输出维度
```

`num_discern`：

```
第一层：(784 + 1) × 32 = 25 120
第二层：(32 + 1) × 10  =    330
合计：25 450
```

### 6.5 MLP 怎么训练

1. **前向**：输入 → 隐藏层 → 输出层，得到 10 个得分；
2. **损失**：softmax + 交叉熵，算预测和真实标签的差距；
3. **反向传播**：用链式法则算每个权重对损失的梯度；
4. **更新**：Adam / SGD 按梯度调整权重；
5. **重复**：遍历训练集很多轮（epoch）。

Keras 里就是：

```python
model.compile(optimizer="adam",
              loss="sparse_categorical_crossentropy",
              metrics=["accuracy"])
model.fit(x_train, y_train, epochs=10, batch_size=128)
```

反向传播的细节不需要在这台设备上手推，但要知道：**每个权重都会收到一个“你该往哪个方向调整”的信号，调整幅度由学习率决定。**

### 6.6 MLP 的优点

- 结构简单，容易实现（C 里两个循环就完成前向）；
- 参数少、内存小，适合单片机；
- 对低维特征、表格数据、已经展平的向量很有效；
- 训练快，容易调试。

### 6.7 MLP 的缺点

- **忽略空间结构**：28×28 被拉成 784，模型不知道哪些像素相邻；
- **平移敏感**：数字往右移 3 个像素，输入向量完全不同，权重必须重新学；
- **参数效率低**：图像越大，第一层参数爆炸。比如 224×224×3 的图，接 128 个隐藏神经元，第一层就是 150 528 × 128 ≈ 1 900 万参数；
- **没有权重共享**：同一个“竖笔画检测器”在图像左上角和右下角要各学一遍。

所以 `num_discern` 才需要包围盒裁剪 + 质心居中：**用预处理替 MLP 消除平移差异。**

### 6.8 MLP 不是“一个模型”，而是一类模型

“MLP”只规定全连接 + 前馈，不规定：

- 有多少层；
- 每层多少神经元；
- 用什么激活函数；
- 输出是什么任务。

`784-32-10`、`784-128-64-10`、`10-10-10` 都是 MLP。

## 7. CNN 是什么

### 7.1 动机

MLP 把图像拉平，丢掉了二维结构。CNN（Convolutional Neural Network，卷积神经网络）的设计目标是：

- **局部性**：一个神经元只看图像的一小块，而不是整张图；
- **平移等变性**：同一个图案出现在不同位置，用同一个滤波器都能检测到；
- **权重共享**：同一个滤波器在全图滑动，参数不随位置增加；
- **层级特征**：边缘 → 笔画 → 部件 → 数字。

### 7.2 卷积层

一个卷积层有若干个**滤波器（kernel/filter）**，每个滤波器是一个小矩阵，比如 3×3。

它在图像上滑动，在每个位置做点积：

```
output[i, j, k] = Σ_{c, u, v} input[i*s+u, j*s+v, c] * kernel[u, v, c, k] + bias[k]
```

- `i, j`：输出位置；
- `c`：输入通道；
- `k`：第几个滤波器；
- `u, v`：滤波器内的偏移；
- `s`：步长 stride；
- 填充 padding 控制边缘。

一个滤波器输出一张**特征图（feature map）**；多个滤波器输出多张特征图，形成通道维。

输出尺寸：

```
out_h = (in_h - k_h + 2*pad) / stride + 1
out_w = (in_w - k_w + 2*pad) / stride + 1
```

### 7.3 池化层

池化用来降采样：

- MaxPool 2×2：每个 2×2 区域取最大值；
- AveragePool：取平均。

作用：

- 减少空间尺寸和计算量；
- 扩大感受野；
- 提供一定的平移不变性；
- 没有参数。

### 7.4 一个 MNIST CNN 的例子

```
输入 28×28×1
  │ Conv 3×3, 8 个滤波器, stride 1, valid
  ▼
26×26×8
  │ ReLU
  ▼
26×26×8
  │ MaxPool 2×2
  ▼
13×13×8
  │ Conv 3×3, 16 个滤波器
  ▼
11×11×16
  │ ReLU
  ▼
11×11×16
  │ MaxPool 2×2
  ▼
5×5×16
  │ Flatten
  ▼
400
  │ Dense 10
  ▼
10
```

参数量：

| 层 | 计算 | 参数量 |
|---|---|---:|
| Conv1 3×3, 1→8 | `3*3*1*8 + 8` | 80 |
| Conv2 3×3, 8→16 | `3*3*8*16 + 16` | 1 168 |
| Dense 400→10 | `400*10 + 10` | 4 010 |
| **合计** | | **5 258** |

对比 MLP 的 25 450 个参数，CNN 反而更小，但 MNIST 准确率通常能到 98% 以上。

> 注意：CNN **参数少**不代表**计算少**。卷积的乘加次数往往比同规模 MLP 多，因为每个滤波器要在所有位置滑动。上例的卷积乘加约 18.8 万次，而 MLP 只有 2.5 万次。CNN 是用“更多计算”换“更少参数、更好泛化”。

如果分类头是 `Flatten → Dense 32 → Dense 10`，参数量：

```
400*32 + 32 = 12 832
32*10 + 10  =    330
合计：80 + 1 168 + 12 832 + 330 = 14 410
```

### 7.5 感受野与层级特征

- 第一层 3×3 卷积只看 3×3 像素，学到边缘、角点；
- 第二层 3×3 卷积看第一层的 3×3 特征图，对应原图 5×5 区域；
- 层数越深，感受野越大，能组合出笔画、圈、钩、整个数字。

这就是 CNN 的“层级特征”。

### 7.6 CNN 和 MLP 的关系

一个典型的 CNN 分两部分：

```
特征提取器（Conv + ReLU + Pool）  →  分类头（Flatten + Dense + Softmax）
```

**分类头本身就是一个 MLP。**

所以：

- CNN = 卷积特征提取 + MLP 分类头；
- MLP 是 CNN 的组成部分；
- 把 CNN 的卷积层换成全连接，就退化成 MLP；
- 把 MLP 的第一层换成“局部连接 + 权重共享”，就得到卷积层。

### 7.7 CNN 的优缺点

优点：

- 参数效率高，适合图像；
- 平移等变性好，对位置变化更鲁棒；
- 层级特征强，准确率高；
- 权重共享，模型不随图像尺寸爆炸。

缺点：

- 结构复杂，实现和调试难度高；
- 激活内存大（多通道特征图），TFLM 的 arena 要更大；
- 卷积计算量大，单片机需要优化（depthwise separable、int8、CMSIS-NN）；
- 小数据/简单任务上不一定比 MLP 好。

激活内存的量级：上例的中间特征图约 `5 408 + 1 352 + 1 936 + 400 ≈ 9 100` 个值，加上输入 784，约 1 万个值；而 MLP 只有 `784 + 32 + 10 ≈ 826` 个值。**CNN 省权重，但费激活内存。**

## 8. 它们之间的联系（重点）

### 8.1 层是角色，网络是组织方式

| 概念 | 类别 | 说明 |
|---|---|---|
| 输入层 | 角色/位置 | 数据入口，无参数 |
| 隐藏层 | 角色/位置 | 中间变换，有参数 |
| 输出层 | 角色/位置 | 任务出口，有参数 |
| MLP | 网络架构 | 相邻层全连接的前馈网络 |
| CNN | 网络架构 | 局部连接 + 权重共享的前馈网络 |

**输入层、隐藏层、输出层是“位置角色”；MLP、CNN 是“连接方式”。**

任何 MLP 和 CNN 都有输入层、隐藏层、输出层。

### 8.2 共享同一个骨架

```
输入层 → 隐藏层（一个或多个）→ 输出层
```

- MLP 的隐藏层是 **Dense + 激活**；
- CNN 的隐藏层是 **Conv + 激活 + Pool**；
- 输出层通常都是 **Dense + 任务激活**；
- 输入层都是数据张量。

所以从“层的角色”看，它们没有区别；区别在隐藏层的**连接模式**。

### 8.3 MLP 和 CNN 的连接模式对比

| 特性 | MLP | CNN |
|---|---|---|
| 连接方式 | 全连接 | 局部连接 |
| 权重共享 | 无 | 有（同一滤波器全图滑动） |
| 空间结构 | 忽略（拉平） | 保留（H×W×C） |
| 平移等变性 | 无 | 有 |
| 参数效率 | 低（图像越大越糟） | 高 |
| 计算量 | 较小 | 通常较大 |
| 激活内存 | 小 | 大 |
| 典型隐藏层 | Dense + ReLU | Conv + ReLU + Pool |
| 典型输出 | Dense + Softmax | Flatten + Dense + Softmax |
| MNIST 准确率 | 约 96% | 约 98%+ |
| 实现难度 | 低 | 中/高 |

### 8.4 一个重要的等价视角

- **全连接层可以看作“卷积核大小等于整张输入”的卷积**：每个输出神经元都看全部输入，只有一“个”位置，所以没有权重共享。
- **卷积层可以看作“稀疏连接 + 权重绑定”的全连接层**：每个输出只连局部输入，而且不同位置共用同一组权重。

因此：

> **CNN 不是和 MLP 并列的另一种东西，而是给 MLP 加了“局部性 + 平移等变”先验的版本。**

### 8.5 训练方式完全一样

无论 MLP 还是 CNN：

1. 前向得到输出；
2. 算损失（交叉熵/MSE）；
3. 反向传播算梯度；
4. 优化器更新权重。

卷积和池化的反向传播公式不同，但框架替你实现了。你写的 `model.fit()` 对 MLP 和 CNN 是同一套。

### 8.6 量化也一样

- 量化作用于**每一层的权重和激活张量**；
- 输入层/输出层是量化模型的边界，需要 scale/zero_point；
- MLP 的激活只有 32 维，CNN 的激活是多通道特征图，arena 占用更大；
- TFLM 对 Conv/Pool 有专门的 int8 算子，但内存规划更复杂。

## 10. 常见误解

1. **“输入层有权重”**：没有。输入层只是数据容器。
2. **“784-32-10 是三层网络”**：按“带权重的层”算是 2 层；按“包括输入层”算是 3 层。说“1 个隐藏层”最准确。
3. **“输出层一定要 softmax”**：不一定。很多框架输出 logits，softmax 放在损失函数里；推理只用 argmax。
4. **“CNN 就是层数更多的 MLP”**：不是。CNN 的区别是局部连接和权重共享，不是深度。
5. **“参数越多越好”**：不。参数多容易过拟合，推理也更慢。
6. **“MLP 不能做图像”**：能做，只是参数效率低、对平移敏感；小图（28×28）上 MLP 仍然可用。
7. **“CNN 一定比 MLP 好”**：数据少、任务简单、算力紧张时，MLP 可能更合适。
8. **“卷积就是严格数学卷积”**：深度学习里的卷积通常是**互相关**（不翻转核），框架这么叫而已。
9. **“展平顺序无所谓”**：非常要紧。训练和推理的 `y*28+x` 必须一致，否则权重全错位。
10. **“隐藏层特征一定能解释”**：不一定。32 个神经元可能学到可辨认的笔画模板，也可能是难以命名的组合；可视化权重只是帮助理解，不是严格解释。

## 11. 一条学习路径

1. **手算一个神经元**：给 3 个输入、3 个权重、1 个偏置，算 `z` 和 `ReLU(z)`。
2. **手算一层**：把 784 维输入乘 `W1`，得到 32 维隐藏层，理解矩阵形状。
3. **理解 XOR**：为什么没有隐藏层不行，有隐藏层就行。
4. **跑通当前 MLP**：对照 `num_discern_model.c`，确认每个数组的形状和下标。
5. **可视化权重**：把 `nd_w1` 的某一列 reshape 成 28×28，看这个隐藏神经元偏好什么图案。
6. **写一个小 CNN**（Keras，MNIST）：`Conv → ReLU → Pool → Conv → ReLU → Pool → Flatten → Dense → Softmax`，对比参数量和准确率。
7. **对比推理**：同一个数字，MLP 和 CNN 各错在哪里；平移、缩放、粗细变化时谁更稳。
8. **量化**：先做 MLP 的 int8 PTQ，再做 CNN 的 int8 PTQ，观察准确率和 arena 大小。
9. **上 TFLM**：从 MLP 开始，再到 CNN；先跑通 `MicroInterpreter`，再调 arena 大小和算子。

## 12. 术语表

| 术语 | 含义 |
|---|---|
| **张量（tensor）** | 多维数组；标量是 0 维，向量 1 维，矩阵 2 维，图像批次 4 维 |
| **层（layer）** | 一个可微函数，把输入张量映射成输出张量 |
| **Dense / 全连接层** | 每个输出神经元连到所有输入神经元；Keras 叫 `Dense`，PyTorch 叫 `Linear` |
| **权重（weight）** | 可学习参数，决定输入的重要性 |
| **偏置（bias）** | 可学习参数，平移激活阈值 |
| **激活函数（activation）** | 非线性函数，如 ReLU、Sigmoid、Tanh、Softmax |
| **logits** | softmax 之前的原始得分 |
| **softmax** | 把一组得分变成概率分布 |
| **交叉熵（cross-entropy）** | 分类任务常用损失，衡量预测分布与真实标签的差距 |
| **反向传播（backpropagation）** | 用链式法则计算每个参数的梯度 |
| **epoch** | 遍历整个训练集一次 |
| **batch** | 一次前向/反向使用的样本数 |
| **学习率（learning rate）** | 每次参数更新的步长 |
| **展平（flatten）** | 把多维张量按固定顺序拉成一维向量 |
| **通道（channel）** | 特征图的深度维；RGB 图有 3 个通道，卷积层有多个输出通道 |
| **卷积核 / 滤波器（kernel/filter）** | 卷积层的小矩阵，在输入上滑动做点积 |
| **步长（stride）** | 卷积核每次滑动的像素数 |
| **填充（padding）** | 在输入边缘补零，控制输出尺寸 |
| **特征图（feature map）** | 一个滤波器在整张输入上卷积后的输出 |
| **感受野（receptive field）** | 一个神经元在原始输入上“看到”的区域 |
| **池化（pooling）** | 降采样操作，如 MaxPool、AveragePool |
| **参数 vs 超参数** | 参数是训练学出来的（权重/偏置）；超参数是人选的（层数、宽度、学习率） |

## 13. 一页总结

- **输入层**：数据的容器，没有参数，规定尺寸、顺序、极性、归一化等契约。
- **隐藏层**：把原始数据变换成更有用的表示，有权重、偏置、激活；宽度和深度决定容量。
- **输出层**：把表示映射成任务答案；多分类常用 logits + softmax，推理用 argmax。
- **MLP**：相邻层全连接的前馈网络；结构简单、参数少，但忽略空间结构、平移敏感。
- **CNN**：局部连接 + 权重共享的前馈网络；参数效率高、平移等变、准确率高，但计算和激活内存更大。
- **联系**：三者是“位置角色”，MLP/CNN 是“组织方式”；它们共享“输入 → 隐藏 → 输出”的骨架和同一套训练/量化流程；CNN 的分类头通常就是一个 MLP。

> 你现在的 `784 → 32 → 10` 就是最小可用的“入口 → 一个加工厂 → 出口”；等这个吃透，再把隐藏层换成 `Conv + Pool`，就是 CNN 了。
