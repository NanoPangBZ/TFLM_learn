# MLP 单隐藏层与多隐藏层的区别

> 记录：2026-10-25
> 相关脚本：[train_mlp_baseline.py](train_mlp_baseline.py)
> 相关说明：[README.md](README.md)

## 0. 术语

- **单层 MLP**：只有 **1 个隐藏层**，例如 `784 → 64 → 10`；
- **多层 MLP**：有 **2 个及以上隐藏层**，例如 `784 → 128 → 64 → 10`。

输入层和输出层不算“隐藏层”。当前脚本默认是单隐藏层 `784 → 64 → 10`。

## 1. 结构

```text
单层：
784 → Dense(64, ReLU) → Dense(10, Softmax)

多层：
784 → Dense(128, ReLU)
    → Dense(64, ReLU)
    → Dense(10, Softmax)
```

单层只做一次非线性变换；多层做多次非线性组合。

**关键：如果没有 ReLU 等激活函数，多层会退化成一层线性变换，加层没有意义。**

## 2. 核心区别

| 对比项 | 单隐藏层 | 多隐藏层 |
|---|---|---|
| 特征层级 | 一层特征 | 多层组合，更抽象 |
| 表达能力 | 足够宽就能逼近复杂函数 | 某些函数可用更少参数表示 |
| 参数效率 | 往往需要更宽 | 可以更深、更窄 |
| 训练难度 | 低 | 高，对初始化/学习率更敏感 |
| 过拟合风险 | 相对低 | 相对高，需要正则化 |
| 训练速度 | 快 | 慢 |
| 超参数 | 少 | 多（层数、宽度、正则） |
| 可解释性 | 相对容易 | 更难 |
| 适合场景 | 简单任务、基线 | 复杂函数、大数据 |

## 3. 理论上的区别

### 单层：万能逼近

理论上，一个隐藏层只要**足够宽**，就可以逼近任意连续函数（万能逼近定理）。

但要注意：

- “足够宽”可能非常宽，参数很多；
- 定理只说明“存在”，不保证训练一定能找到；
- 不保证泛化到新数据。

所以“单层能逼近一切”不等于“单层最好”。

### 多层：深度效率

某些函数用深层网络表示，比用一层超宽网络更省参数。

直观理解：

```text
单层：一次性把输入映射到特征
多层：先学简单组合，再学组合的组合，逐层抽象
```

例如图像里可以想象成：

```text
边缘 → 笔画 → 局部形状 → 数字
```

不过 MLP 的输入已经被拉平成 784 维，空间结构丢了；多层 MLP 仍然不如 CNN 擅长这种层级特征。

## 4. 参数量对比

Dense 层参数量：

```text
(n_in + 1) × n_out
```

其中 `+1` 是每个输出神经元的偏置。

| 结构 | 参数量 |
|---|---:|
| `784 → 64 → 10` | 50 890 |
| `784 → 128 → 10` | 101 770 |
| `784 → 64 → 64 → 10` | 55 050 |
| `784 → 128 → 64 → 10` | 109 386 |

可以看到：

- 一层 128 个神经元约 10.2 万参数；
- 两层 64+64 约 5.5 万参数。

**两层 64+64 比一层 128 参数更少**，但非线性组合更多。这是“深度可能更参数高效”的直观例子。

参数少不代表准确率一定高，要看任务、数据和训练情况。

## 5. 训练上的区别

### 单层

优点：

- 容易训练；
- 对学习率、初始化不敏感；
- 训练快；
- 不容易过拟合；
- 适合先做基线。

缺点：

- 复杂任务可能欠拟合；
- 需要很宽才能表达复杂函数；
- 特征只做一次变换。

### 多层

优点：

- 能组合出更复杂的特征；
- 某些任务上参数效率更高；
- 理论上可以表示更复杂的决策边界。

缺点：

- 更难优化：梯度消失/爆炸、初始化敏感；
- 需要更多数据；
- 更容易过拟合；
- 训练更慢；
- 调参空间更大。

ReLU 缓解了梯度消失，但深层 MLP 仍然比单层难训。

## 6. 在 MNIST 上的实际情况

MNIST 是比较简单的任务：

- 单层 `784 → 64 → 10` 验证集约 **96.4%**；
- 加到两层不一定明显提升，可能持平甚至略差；
- 想明显提升，通常不是“加深 MLP”，而是：
  - 加宽隐藏层；
  - 用 CNN；
  - 更好的预处理；
  - 数据增强；
  - 正则化/调学习率。

因为 MLP 把 28×28 拉平成 784，已经丢掉了二维局部结构；多加几层 Dense 也补不回卷积的归纳偏置。

## 7. 怎么选

### 先单层

从 `784 → 64 → 10` 或 `784 → 128 → 10` 开始，记录：

- 训练准确率；
- 验证准确率；
- 参数量；
- 训练时间。

### 判断欠拟合/过拟合

| 现象 | 含义 | 处理 |
|---|---|---|
| 训练低、验证低 | 欠拟合 | 加宽、加层、训练更久 |
| 训练高、验证低 | 过拟合 | dropout、权重衰减、早停、减宽度 |
| 训练和验证都高 | 正常 | 可以停止或微调 |

### 加层的时机

只有在**单层明显欠拟合**，或者任务确实需要层级特征时，才考虑加第二层。

不要因为“深度听起来更强”就直接堆层。

## 8. 一句话

**单层是“一次非线性变换”，多层是“多次非线性组合”。单层足够宽就能逼近复杂函数，但可能参数效率低；多层可能更省参数、表达能力更强，但更难训练、更容易过拟合。MNIST 上先把单层调好，通常比盲目加层更有效。**
